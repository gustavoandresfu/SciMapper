# Colab Demo (carpeta independiente)

Esta carpeta es solo para experimentar en Google Colab sin tocar el código principal.

## Uso
1. Sube `SciMapper_Colab.ipynb` a Colab o ábrelo desde GitHub.
2. Ejecuta las celdas en orden.
3. Descarga `scimapper_resultados.zip`.

No modifica `core/`, `main.py` ni el código principal.
